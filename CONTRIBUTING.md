# Contributing

Real appliance behavior varies a lot, so real-world test data is especially useful.

Useful contributions include:

- anonymized CSV prediction logs;
- examples from different appliance brands and smart plugs;
- bug reports with the cycle duration, predicted remaining time and power/energy behavior;
- improvements to generic entity configuration;
- UI/card compatibility examples.

Please remove private Home Assistant entity names, addresses or other personal information before sharing logs or configuration.
